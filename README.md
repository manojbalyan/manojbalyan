### 🚀 Projects

#### 🩺 [Parkinson's Disease Detection System](https://parkinsons-detection-ai.streamlit.app/)
An end-to-end clinical machine learning web application that screens for early-stage Parkinson's Disease from voice recordings (`/a/` vowel phonation).
- Extracts 22 acoustic biomedical features (Jitter, Shimmer, HNR, RPDE) using custom signal processing.
- Powered by a 4-layer PyTorch MLP achieving **97.4% test accuracy** and **96.6% recall**.
- Deployed as an interactive real-time web app on Streamlit Cloud.
- 🔗 **[Live Demo](https://parkinsons-detection-ai.streamlit.app/)** | **[Source Code](https://github.com/manojbalyan/parkinsons-disease-detection)**

#### 🛒 [ShopNest — Full-Stack E-Commerce Platform](https://shopnest-6tmy.onrender.com/)
A responsive full-stack online shopping platform built with the MERN stack.
- Features JWT authentication, role-based access control, product browsing, and cart management.
- Backed by MongoDB schemas designed with Mongoose for clean data handling.
- Containerized with Docker and deployed with an automated GitHub Actions CI/CD pipeline to Render.
- 🔗 **[Live Demo](https://shopnest-6tmy.onrender.com/)**
